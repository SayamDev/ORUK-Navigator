# Triage labels

The engineering skills use five canonical triage roles. This repository uses the same strings as its GitHub label names.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The work is specified and suitable for an agent. |
| `ready-for-human` | `ready-for-human` | The work requires human implementation or judgement. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill refers to a triage role, apply the corresponding GitHub label above.
