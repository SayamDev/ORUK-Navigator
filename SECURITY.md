# Security policy

## Reporting a vulnerability

Use GitHub’s private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability, secret, personal-data exposure, or exploit details.

For ordinary catalogue corrections, use the product’s correction form without including names, contact details, health information, benefits information, case numbers, or other personal data.

## Supported version

Until the pilot is deployed and tagged, only the latest commit on `main` is supported. Security fixes are applied forward and verified through the release gates.
